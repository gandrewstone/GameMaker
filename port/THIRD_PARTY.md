# Third-party material in the port

What `port/` uses or embeds that is not original GameMaker code, and under which terms. License texts are in
[`licenses/`](licenses/). A binary distribution of `gmplay` should ship this file and that folder.

| Component | Used for | How | License |
|---|---|---|---|
| [raylib](https://www.raylib.com/) 5.5 | window, input, audio device | fetched by CMake at build time, linked statically | zlib/libpng ([text](licenses/raylib-LICENSE.txt)); no attribution needed in binaries |
| [ymfm](https://github.com/aaronsgiles/ymfm) (Aaron Giles), commit pinned in `CMakeLists.txt` | OPL2 (YM3812) FM synthesis for CMF music | fetched by CMake, compiled into `gmplat` | BSD-3-Clause ([text](licenses/ymfm-LICENSE.txt)); binaries must reproduce the copyright notice, which this file and the license text do |
| [Unscii](https://github.com/viznut/unscii) 8 (Viznut), commit in the header of `src/font8x8.h` | 8x8 character font (BIOS "ROM font" and text mode) | glyph data embedded in `src/font8x8.h`, generated by `tools/mkfont.ps1` | public domain / CC0, per the author's README. Four glyphs not in Unscii (0x0F, 0x7F, 0xA9, 0xF9) were drawn for this project |
| Microsoft Visual C++ runtime | C runtime | dynamic or static link as built | Microsoft redistribution terms; not bundled by the repo |
| [Emscripten](https://emscripten.org/) runtime | the JavaScript glue and libc parts that the compiler puts into the web build (`gmplay.js`, `gmplay.wasm`) | generated by the Emscripten compiler when building the web distributable | MIT or University of Illinois/NCSA, your choice ([text](licenses/emscripten-LICENSE.txt)); the generated files do not repeat it, so the web distributable ships the text in `licenses/` |

## The GameMaker code itself

The repository's `LICENSE` is the MIT license, copyright 2014 gandrewstone (the original author). Some source file headers
from 1994 say "NOT PUBLIC DOMAIN" or "Copyright 1994 G. Andrew Stone"; those are older notices, and the repository
license is the author's later grant. The files under `code/` that the port modifies keep their original headers.

## Not covered by the port, and not settled here

These sit in the repository but are not part of the port. Redistributing them is a separate question that needs the
rights holders, and I could not determine their status:

- `tools/BORLANDC/`: the Borland C++ 3.1 compiler, linker, headers and libraries (Borland / Embarcadero).
- `cd/` and `runtime/`: the GameMaker CD image, including sample games, shareware games and their art, music and sound
  (many authors; the shareware games each ship their own executables), and third-party DOS utilities such as `lharc.exe`
  (Haruyasu Yoshizaki).
- The Creative Labs sound driver and library files (`SBCL.LIB`, `sndblast.drv`). The port does not use them (it replaces
  them with its own FM driver), but they are in the repository.

An earlier version of the port generated `font8x8.h` from a Windows `.FON` font file. That was replaced by Unscii
because Microsoft's font data should not be redistributed, and the extraction tool was removed.
